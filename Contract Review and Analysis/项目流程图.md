# 合同评审系统流程图

## 1. 系统整体流程图

```mermaid
flowchart TD
    A[用户注册] --> B[管理员审批]
    B --> C[用户登录]
    C --> D[上传合同]
    D --> E[智能审核]
    E --> F{审核结果}
    F -->|通过| G[进入审批]
    F -->|不通过| H[生成审核报告]
    H --> I[修改合同]
    I --> D
    G --> J[部门审批]
    J --> K{审批结果}
    K -->|通过| L[合同生效]
    K -->|驳回| I
    L --> M[合同归档]
```

## 2. 用户注册流程

```mermaid
flowchart TD
    A[用户填写注册信息] --> B[提交注册申请]
    B --> C[系统验证信息]
    C --> D[管理员审核]
    D --> E{审核结果}
    E -->|通过| F[账户激活]
    E -->|驳回| G[注册失败通知]
    F --> H[注册成功通知]
    G --> I[用户重新注册]
    I --> A
```

## 3. 合同上传流程

```mermaid
flowchart TD
    A[用户登录系统] --> B[进入合同管理]
    B --> C[点击上传合同]
    C --> D[填写合同信息]
    D --> E[选择合同分类]
    E --> F[选择合同子分类]
    F --> G[上传合同文件]
    G --> H[提交合同]
    H --> I[系统存储文件]
    I --> J[触发智能审核]
    J --> K[返回上传成功通知]
```

## 4. 智能审核流程

```mermaid
flowchart TD
    A[合同上传完成] --> B[提取合同内容]
    B --> C[读取对应分类规则]
    C --> D[Agent工作流分析]
    D --> E[规则匹配检查]
    E --> F[风险点识别]
    F --> G[生成审核报告]
    G --> H{审核结果}
    H -->|通过| I[标记为待审批]
    H -->|不通过| J[标记为需修改]
    I --> K[推送审批任务]
    J --> L[通知上传用户]
```

## 5. 审批流程

```mermaid
flowchart TD
    A[合同进入审批队列] --> B[系统分配审批人]
    B --> C[审批人接收任务]
    C --> D[查看合同信息]
    D --> E[查看审核报告]
    E --> F[查看合同文件]
    F --> G[填写审批意见]
    G --> H{审批结果}
    H -->|同意| I[标记为已审批]
    H -->|驳回| J[标记为需修改]
    H -->|转批| K[重新分配审批人]
    I --> L[通知上传用户]
    J --> M[通知上传用户]
    K --> C
```
