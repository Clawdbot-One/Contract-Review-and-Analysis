# 合同评审系统技术架构设计

## 1. 系统概述

本系统是一个专为机构或系统内人员设计的合同评审和分析平台，支持本地化部署，集成人工智能审核功能，实现合同全流程管理和记录。

## 2. 技术栈选择

### 2.1 前端技术
- **框架**：React 18
- **语言**：TypeScript
- **UI库**：Ant Design Pro
- **状态管理**：Redux Toolkit
- **路由**：React Router v6
- **表单**：Formik + Yup
- **文件上传**：react-uploady
- **图表**：ECharts
- **样式**：Tailwind CSS

### 2.2 后端技术
- **语言**：Node.js
- **框架**：Express.js
- **数据库**：PostgreSQL
- **缓存**：Redis
- **认证**：JWT
- **文件存储**：本地文件系统 + MinIO（可选）
- **任务队列**：Bull.js

### 2.3 AI/Agent集成
- **OpenAI API**：用于智能合同分析
- **LangChain**：用于构建Agent工作流
- **Pinecone**：用于向量存储（可选）

## 5. 系统流程

### 5.1 合同上传流程
1. 用户登录系统
2. 上传合同文件
3. 选择合同分类和子分类
4. 系统存储文件到指定目录
5. 触发智能审核流程

### 5.2 智能审核流程
1. 系统提取合同内容
2. 读取对应分类的审核规则
3. Agent工作流进行规则匹配和分析
4. 生成审核报告
5. 根据审核结果决定是否进入终审

### 5.3 审批流程
1. 合同进入审批队列
2. 系统分配给对应审批人
3. 审批人查看合同和审核报告
4. 审批人给出审批意见
5. 系统记录审批结果
