# 产品销售合同审核规则

## 1. 合同基本信息
- [ ] 合同双方名称、地址、联系方式完整
- [ ] 合同编号、签订日期明确
- [ ] 合同有效期清晰

## 2. 产品信息
- [ ] 产品名称、规格、型号、数量明确
- [ ] 产品质量标准和验收标准明确
- [ ] 产品交付时间、地点、方式明确

## 3. 价格与付款
- [ ] 产品单价、总价明确
- [ ] 付款方式、付款时间明确
- [ ] 发票开具要求明确

## 4. 违约责任
- [ ] 卖方违约责任明确
- [ ] 买方违约责任明确
- [ ] 违约赔偿标准明确

## 5. 争议解决
- [ ] 争议解决方式明确（仲裁或诉讼）
- [ ] 管辖法院或仲裁机构明确

## 6. 其他条款
- [ ] 保密条款
- [ ] 不可抗力条款
- [ ] 合同生效条件
- [ ] 合同份数及效力
