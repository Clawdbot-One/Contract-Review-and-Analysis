# 设备采购合同审核规则

## 1. 合同基本信息
- [ ] 合同双方名称、地址、联系方式完整
- [ ] 合同编号、签订日期明确
- [ ] 合同有效期清晰

## 2. 设备信息
- [ ] 设备名称、规格、型号、数量明确
- [ ] 设备技术参数和配置明确
- [ ] 设备质量标准和验收标准明确

## 3. 价格与付款
- [ ] 设备单价、总价明确
- [ ] 付款方式、付款时间明确
- [ ] 发票开具要求明确
- [ ] 质保金条款明确

## 4. 交付与安装
- [ ] 交付时间、地点明确
- [ ] 安装、调试要求明确
- [ ] 验收流程和标准明确

## 5. 售后服务
- [ ] 质保期明确
- [ ] 售后服务内容和响应时间明确
- [ ] 维修、保养条款明确

## 6. 违约责任
- [ ] 卖方违约责任明确
- [ ] 买方违约责任明确
- [ ] 违约赔偿标准明确

## 7. 争议解决
- [ ] 争议解决方式明确（仲裁或诉讼）
- [ ] 管辖法院或仲裁机构明确

## 8. 其他条款
- [ ] 保密条款
- [ ] 不可抗力条款
- [ ] 合同生效条件
- [ ] 合同份数及效力
